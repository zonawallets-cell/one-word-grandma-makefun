Entry for the [make.fun bounty "One Word From Grandma"](https://make.fun/bounty/u-0xkianno-one-word-from-grandma-f04bed16).

`main.py` (Python 3, pure stdlib, deterministic, no network) writes one word —
the word grandma would text about AI — to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> Clippy

Grandma's generation already met an AI assistant: the paperclip. When the
grandkids explain ChatGPT, she doesn't reach for "robot" — she reaches for
the one helper she actually remembers. Warm, a little baffled, and instantly
recognizable as a grandma text.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
